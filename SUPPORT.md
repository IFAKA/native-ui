# Support

- Use GitHub Discussions for questions, ideas, and examples.
- Use the bug issue form for reproducible defects.
- Use the feature proposal form for new public capabilities.
- Use private vulnerability reporting for security issues.

Native UI is currently experimental. Maintainers do not guarantee response times or production support before 1.0.
## Documentation

The static documentation starts at [`site/index.html`](site/index.html). It demonstrates the HTML-first path, native no-JavaScript behavior, the public vocabulary, and links to the support, accessibility, browser, security, and contribution guides.
