# Governance

Native UI currently uses a maintainer-led model.

## Decision making

- Documentation and bug fixes may proceed through ordinary review.
- Public API, browser policy, dependencies, accessibility contracts, and architectural changes require a written specification and maintainer approval.
- Decisions optimize for semantic HTML, usability, accessibility, small public surface, and long-term compatibility—not component count.
- Material decisions are recorded in `docs/decisions/`.

## Roles

- **Contributors** propose and implement changes.
- **Reviewers** provide consistent, evidence-based review.
- **Maintainers** approve public contracts, releases, security responses, and governance changes.

As the community grows, contributor and maintainer nomination criteria will be documented before authority is delegated.
