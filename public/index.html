Semantic HTML · zero runtime dependencies

Give agents a smaller UI vocabulary.

Native UI makes semantic HTML attractive, adaptive, and practical. Start with what the browser understands, then name only the layout and visual relationships your interface actually needs.

Try the examplesOpen the comparison lab

HTML owns meaning. CSS owns presentation. Your app owns business logic.

That boundary gives an AI coding agent a compact authoring contract: native elements first, intrinsic layout second, minimal progressive enhancement only when the platform cannot express the interaction.

This is a project goal and design thesis, not a claim of exact token savings.

From intent to interface

1. Install the stylesheet

npm install @ifaka/native-ui

There is no component runtime, provider, or generated DOM.

2. Write real HTML

<label>Email <input type="email" required></label>

Labels, validation, focus, disclosure, and submission stay native.

3. Add layout intent

<section class="nui-grid">...</section>

Classes describe relationships rather than every visual property.
