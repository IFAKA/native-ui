The foundation

Three layers, one source of truth.

A compact contract is easier for people and agents to learn, review, and carry into the next screen.

01

Native HTML first

Links go places. Buttons perform actions. Forms validate, submit, and report errors. Disclosure, focus, and source order keep their browser meaning.

02

Small CSS contracts

Use stack, cluster, grid, readable, and container relationships. Let intrinsic sizing and one DOM handle narrow screens before adding more rules.

03

Progressive behavior

Add JavaScript only when HTML cannot express the compound interaction. Keep the no-script path useful and the application’s business logic local.
