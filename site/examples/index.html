How to read the layout examples

nui-stack means “place these items in one vertical rhythm.” nui-cluster means “let these actions wrap as a group.” nui-grid means “fit repeated items into intrinsic columns.” nui-readable limits long-form text to a comfortable measure. nui-container centers a page region without requiring JavaScript.

They are layout relationships, not components. Start with semantic elements, add one relationship class, and keep the same DOM at every width.
