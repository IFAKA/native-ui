# Foundation Technical Plan

Implement a manifest-governed CSS and behavior package with one compiled stylesheet, one optional ES module, canonical recipes, benchmark pages, and a deterministic Node-based analyzer. Build in dependency order: governance and measurements, classless elements, intrinsic layout, compositions, behavior audit, analyzer, upstream research adapters, documentation, then release hardening.

The full engineering sequence, failure gates, commands, and acceptance criteria are in [`../../docs/plans/2026-08-10-native-ui-1.0-implementation-plan.md`](../../docs/plans/2026-08-10-native-ui-1.0-implementation-plan.md).
